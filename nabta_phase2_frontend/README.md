# Nabta mobile frontend (Phase 2, Android-ready in Phase 3)

This folder contains the current merged Nabta frontend: customer shopping, authentication, cart/checkout, orders, admin interface, English/Arabic support, footer/company contact links, and account settings. It uses HTML, CSS, JavaScript, Ionic Core web components, Vite and Capacitor 7.

## Browser development

1. Start Phase 1 Java backend in another terminal using `mvn spring-boot:run`.
2. From this folder, run `npm install`.
3. Run `npm run dev` and open the Vite URL (usually `http://localhost:5173`).

The browser API default is `http://localhost:8080/api` unless `VITE_NABTA_API_BASE` is set in the build environment.

## Android

Use the root Phase 3 instructions. `capacitor.config.ts` sets the app ID to `com.nabta.app`. Local HTTP access is enabled only when the Android preparation script sets `NABTA_ANDROID_DEV_HTTP=true`. Production builds must use a deployed HTTPS API endpoint and must be synced with that development flag unset.

The native `android/` directory is generated by `npx cap add android` on your machine and is a source project. Do not delete it after generation.

## Brand assets

Place your own images at:

- `public/assets/nabta-logo.png` (or `.jpg`)
- `public/assets/nabta-background.jpg` (or `.png`)

## Important boundaries

- Product, customer and order data are fetched from the Java backend/MySQL. Local storage is used only for suitable device-local information such as session, language, current cart, and currently saved-address UI state.
- This phase sets up local Android testing. It does not deploy the backend or configure Firebase push notifications.
- The native Android wrapper must be generated and built on a machine with Android Studio/SDK installed. Follow `../PHASE3-ANDROID-README.md`.
